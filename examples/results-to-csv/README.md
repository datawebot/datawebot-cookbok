# Saved result pages → CSV (no network)

**User problem:** “I already downloaded the extraction. Put it into a file my
spreadsheet or next agent can ingest without running source requests again.”

Use Python 3.11+, no dependencies. Input is the cookbook envelope generated by
[api.py](../amazon-search-to-pdp/api.md): `{ "job": ..., "pages": [...] }`.
This is not a raw single-page CLI response. Only COMPLETED/PARTIAL_COMPLETE data
is accepted; partial status stays attached to every row.

```sh
python3 examples/results-to-csv/export.py work/pdp-results.json > work/products.csv
```

Columns are `job_id`, `job_status`, `record_index`, `data_json`. The last column
is the entire source data object serialized as JSON, so variable blueprint
fields, nested variants and null values are preserved instead of being flattened
with guessed names/currency. For analysis, parse `data_json` and use the discovered
record schema. Original result JSON remains authoritative, including errors.

Cells that could be interpreted as spreadsheet formulas get a leading apostrophe.
Do not strip this protection just to make untrusted source text look cleaner.
CSV quoting is handled by Python; do not concatenate product text into CSV lines.

This recipe makes **zero API/MCP/source calls**, does not schedule anything, and
adds no date/price history that was not already present in the saved records.
Tests use synthetic pages; no real product data is included in the repository.
